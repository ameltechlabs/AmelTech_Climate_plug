# Documentation Status

The full documentation set described in the library's original spec
(`Architecture.md`, `API.md`, `Commands.md`, `OpenMeteo.md`,
`Locations.md`, `URLs.md`, `Sensors.md`, `Platforms.md`, `Cache.md`,
`Security.md`, `Troubleshooting.md`) has not been written yet.

**In the meantime, the most reliable API reference is the source
itself** — every public method in `src/AmelTech_Climate_plug.h` has
either a `[WIRED]` or `[PENDING]` annotation, and every module under
`src/` has a header comment explaining its responsibility and how it
fits into the overall architecture.

See [../PENDING_MODULES.md](../PENDING_MODULES.md) for the exact,
current list of what's implemented vs. still pending across the whole
library, and [../README.md](../README.md) for installation and a
basic usage example.
